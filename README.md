# gpt-test

A tiny Python greeting utility with a CLI entrypoint.

## Quickstart

1. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

2. Run the CLI:

   ```bash
   python main.py "Ada"
   ```

   Expected output:

   ```
   Hello, Ada!
   ```

3. Run tests:

   ```bash
   pytest
   ```
