# 3D 打印耗材管理手机 App（离线版）

一款面向个人的移动端小工具，用于离线记录 3D 打印耗材的库存、使用与采购信息。应用采用 Expo/React Native 开发，所有数据写入设备本地文件（无需账号、无需网络），适合个人或小型工作室自用。

## 功能亮点
- **线材档案**：品牌、材质（PLA/PETG/ABS/TPU 等）、颜色、入库重量、当前剩余重量与开封日期一次性保存。
- **打印扣减**：为每次打印登记耗材用量，自动扣减对应线材卷库存，可添加备注，历史可追溯。
- **提醒**：低库存提醒、开封超期提醒，阈值可在应用内调整，单位可切换 g/kg。
- **采购统计**：记录采购重量与金额，自动按年度聚合支出与购入重量，便于预算与补货决策。
- **完全离线**：不依赖云服务，数据保存为 `filament-data.json` 文件，位于系统的应用沙盒下，可通过手动复制进行备份或迁移。
  
> 说明：仓库未附带自定义图标或启动图，以避免二进制文件上传限制，运行时将使用 Expo 默认资源。

## 运行环境
- Node.js 18+
- Expo CLI（`npm i -g expo`）或使用 Expo Go 直接扫码运行
- iOS 17+/Android 10+ 设备或模拟器

## 快速开始
```bash
npm install
npm run start           # 启动开发服务器，选择 iOS/Android/Web 预览
npm run android         # 直接在已连接的 Android 模拟器/设备上启动
npm run ios             # 直接在 iOS 模拟器上启动
```

首次打开应用会自动创建本地数据文件，后续所有操作（添加线材、记录使用、登记采购、更新阈值）都会即时写入。

## 主要界面与操作
- **配置**：选择重量单位（g/kg），设置低库存提醒阈值与开封天数提醒阈值。
- **添加线材**：输入品牌、材质、颜色、入库重量，可选当前重量与开封日期（留空则默认使用当天）。
- **记录打印消耗**：从线材下拉框中选择一卷，填写本次消耗重量并保存，系统自动扣减库存。
- **采购登记**：记录品牌、材质、颜色、采购重量与价格，可选日期（默认当天）。
- **提醒与统计**：低库存/开封超期列表及时提示；年度统计展示每年累计支出与采购重量。

## 数据位置与备份
- 数据文件默认存储在应用沙盒：`{FileSystem.documentDirectory}/filament-data.json`（在真机上路径因系统而异）。
- 通过设备文件浏览或平台自带的调试工具可导出此文件，用于手动备份或迁移到新设备。

## 注意事项
- 当前版本不包含登录、同步或云备份；如需跨设备同步，请自行手动复制数据文件。
- 库存扣减基于用户输入的打印用量，应用不会与打印机通信，也不解析 G-code。
- 如需扩展二维码扫描、耗材照片或更复杂的统计，可基于现有代码继续迭代。
