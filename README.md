# 3D 打印耗材管理移动端（Expo/React Native）

一款离线运行的手机 App，用于个人记录 3D 打印耗材的库存、使用、采购与提醒信息。项目基于 Expo/React Native，默认使用 Expo 内置图标和启动图，仓库不包含任何二进制资源或 Python 代码。

## 核心能力
- **耗材档案**：为每卷线材保存品牌、材质（PLA/PETG/ABS/TPU 等）、颜色、入库重量、当前重量与开封日期。
- **打印记录与自动扣减**：登记每次打印的耗材消耗量，自动扣减对应线材的剩余重量，附带备注与日期。
- **提醒**：按可配置阈值提示低库存与开封超期，重量单位可在 g/kg 间切换。
- **采购与统计**：记录采购重量与金额，按年度聚合支出与购入重量，便于预算规划。
- **完全离线**：所有数据存储在设备本地的 `filament-data.json` 中，无需账号或网络。

## 环境要求
- Node.js 18+
- npm 或 yarn
- Expo CLI（`npm i -g expo`）或使用 Expo Go 扫码预览
- iOS 17+/Android 10+ 设备或模拟器

## 安装与运行
```bash
npm install
npm run start           # 启动开发服务器，选择 iOS/Android/Web 预览
npm run android         # 在已连接的 Android 模拟器/设备上启动
npm run ios             # 在 iOS 模拟器上启动
```

首次启动会自动创建本地数据文件，后续添加线材、登记打印或采购都会即时写入。

## 使用指南
- **基础设置**：在设置区切换重量单位（g/kg），配置低库存阈值与开封超期天数。
- **添加线材**：录入品牌、材质、颜色、入库重量，可选当前重量和开封日期。
- **记录打印**：选择线材卷，填写本次消耗重量并保存，系统自动扣减库存。
- **登记采购**：记录采购重量、金额与日期，支持补充品牌和材质信息。
- **提醒与统计**：查看低库存/开封超期列表，以及年度支出与采购重量汇总。

## 数据位置与备份
- 数据文件位于应用沙盒：`{FileSystem.documentDirectory}/filament-data.json`（具体路径随平台而变）。
- 可通过设备文件浏览或调试工具手动导出文件用于备份或迁移，流程无需任何后端服务。

## 限制与后续方向
- 当前版本仅支持单设备本地存储，不含同步、云备份或打印机控制接口。
- 若需二维码扫描、耗材照片、或更多统计维度，可在现有 React Native 代码基础上扩展。
